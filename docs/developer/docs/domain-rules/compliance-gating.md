# Compliance Gating

Compliance determines whether user capabilities are allowed.

## Main inputs

- country and jurisdiction
- legal entity type
- KYC status
- sanctions status
- age verification
- explicit account restrictions

## Capability outcome

Compliance feeds user-facing allowances such as:

- funding allowed or blocked
- trading allowed or blocked
- internal review queue visibility for KYC/restriction issues
