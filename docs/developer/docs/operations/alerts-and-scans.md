# Alerts and Scans

The platform can generate operational alerts from:

- ledger invariant scans
- reconciliation drift
- delayed provider callbacks
- stalled settlements
- unusual trading conditions
- stale realtime subscriptions

## Why they matter

The alert layer is the bridge between domain invariants and operator action.
Without it, failures remain buried in raw state instead of surfacing in a review feed.
